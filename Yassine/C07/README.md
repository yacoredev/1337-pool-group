# C07 - Dynamic Memory & String Manipulation

In this project, we explore dynamic memory allocation in C and practice building functions that manipulate strings, arrays, and numerical ranges. The goal is to improve problem-solving skills, memory management, and writing modular reusable code.

---

## Exercises

| Exercise | Description |
|---|---|
| `ft_strdup` | Duplicate a string using dynamic memory |
| `ft_range` | Create an array of integers |
| `ft_ultimate_range` | Allocate and fill a range of integers |
| `ft_strjoin` | Concatenate multiple strings |
| `ft_convert_base` | Convert numbers between bases |
| `ft_split` | Split a string into words |

---

## What I Learned

- Dynamic memory allocation with `malloc`
- Proper memory management with `free`
- String parsing & manipulation
- Pointer arithmetic
- Handling edge cases
- Building reusable helper functions
