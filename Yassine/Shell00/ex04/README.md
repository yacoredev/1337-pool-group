## Commands used

            ls -tmF
            
            
            ls      Lists files and directories in the current directory.
            -t      Sorts the output by modification time.
            -m      Displays the result separated by comma and space.
            -F      Adds a symbol after names:
                        / for directories
                        * for executable files
            
            
            -r      Reverses the order (oldest first).
